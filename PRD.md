# PRD: Интерактивный визуализатор коннектома C. elegans на $mol

## 1. Цель

Создать лёгкое, быстрое, офлайн-работающее браузерное приложение для интерактивного исследования коннектома нематоды C. elegans (302 нейрона, ~7000 синаптических связей). Standalone-приложение на $mol, публикуемое отдельно (не PR в OpenWorm), с последующим предложением сообществу OpenWorm как внешнего инструмента.

Вторичная цель: showcase возможностей $mol (виртуализация, реактивный граф, малый бандл, офлайн) на реальных научных данных.

## 2. Пользователи

- Исследователи и студенты нейробиологии, изучающие C. elegans.
- Участники сообщества OpenWorm.
- Разработчики, оценивающие $mol (вторичная аудитория, в UI не упоминается).

## 3. Данные

### Источники (все открытые)
- Коннектом Cook et al. 2019 (gap junctions + химические синапсы, гермафродит): CSV/XLSX, доступен в репозиториях OpenWorm (`openworm/c302`, `openworm/owmeta`) и на wormwiring.org.
- Классический датасет White et al. 1986 / Varshney et al. 2011 — как альтернативный слой.
- Классификация нейронов: sensory / interneuron / motor / polymodal; принадлежность к ганглиям; нейротрансмиттеры (ACh, GABA, glutamate, dopamine, serotonin) — из WormAtlas / owmeta.

### Модель данных
```ts
type Neuron = {
  id: string          // 'AVAL', 'ASHR', ...
  class: string       // 'AVA', 'ASH'
  type: 'sensory' | 'inter' | 'motor' | 'poly'
  ganglion: string
  neurotransmitter?: string[]
  position?: { x: number, y: number } // анатомическая AP-позиция, если есть
}

type Edge = {
  from: string
  to: string
  kind: 'chemical' | 'gap'
  weight: number      // число синапсов/контактов
}
```

Данные конвертируются офлайн-скриптом (Node/TS) из исходных CSV в один статический JSON (~200–500 КБ), вшиваемый в бандл или лежащий рядом. Никакого рантайм-фетча внешних API. Скрипт конвертации хранится в репо с указанием источника и версии датасета.

## 4. Функциональные требования

### MVP (обязательное)

**F1. Граф-вью.**
- Отрисовка всех 302 нейронов и рёбер (SVG или Canvas — на усмотрение исполнителя; при 7к рёбер Canvas для рёбер + SVG/DOM для узлов допустимая гибридная схема).
- Два режима раскладки:
  - **Послойная**: sensory → interneurons → motor (слева направо), внутри слоя сортировка по ганглию.
  - **Force-directed**: с фиксацией после стабилизации, seed детерминированный.
- Химические синапсы — направленные (стрелка), gap junctions — ненаправленные, визуально различимы (цвет/штрих).
- Толщина ребра ∝ log(weight).

**F2. Интерактив.**
- Hover на нейрон: тултип (имя, тип, ганглий, нейротрансмиттеры, число входов/выходов).
- Клик на нейрон: режим фокуса — подсветка нейрона и его соседей 1-го порядка, остальное затемняется. Повторный клик/Esc — сброс.
- Клик на ребро: тултип (from → to, тип, вес).
- Пан и зум (колесо + drag), кнопка «сбросить вид».

**F3. Фильтры (панель слева/сверху).**
- По типу нейрона (чекбоксы sensory/inter/motor/poly).
- По типу связи (chemical / gap).
- По минимальному весу ребра (слайдер).
- Поиск нейрона по имени с автодополнением; выбор из поиска = фокус на нейроне.

**F4. Пути сигнала.**
- Выбор двух нейронов (например, ASH → AVA → мышечные мотонейроны): подсветка кратчайших путей (BFS по направленным химическим рёбрам, до N=3 путей, длиной до 5 хопов).

**F5. Детальная панель.**
- При фокусе на нейроне: список всех входящих и исходящих связей, сортировка по весу, клик по строке — переход фокуса.

**F6. Офлайн и шаринг.**
- Всё работает как статика без сервера (открыл index.html или задеплоил на GitHub Pages — работает).
- Состояние (фокус, фильтры, раскладка) сериализуется в URL — ссылкой можно поделиться конкретным видом.

### V2 (не делать в MVP, заложить архитектурно)
- Слой «wireless connectome» (нейропептиды) как переключаемый датасет.
- Анатомическая раскладка по реальным координатам тела червя.
- Проигрывание записей нейронной активности (heatmap на узлах по времени).
- Сравнение датасетов (White 1986 vs Cook 2019) с diff-подсветкой.

## 5. Нефункциональные требования

- **Стек**: $mol (актуальная версия из trunk, стандартная структура проекта mam). TypeScript. Без внешних граф-библиотек (d3 и т.п. не тащить; layout-алгоритмы пишутся свои или берутся как маленькие standalone-функции).
- **Производительность**: первый рендер < 1 с на средней машине; пан/зум/hover — 60 fps; фильтрация — без заметной задержки. Использовать виртуализацию $mol для списков (панель связей), не рендерить затемнённые/отфильтрованные рёбра.
- **Размер**: целевой бандл (без данных) — порядка сотен КБ, не мегабайты.
- **Работает** в актуальных Chrome/Firefox/Safari, включая мобильные (адаптив: панель фильтров сворачивается).
- **Язык UI**: английский (аудитория международная).
- **Лицензия**: MIT. В футере — атрибуция источников данных (Cook et al. 2019, OpenWorm, WormAtlas) с ссылками.

## 6. Не входит в объём

- Любая симуляция динамики нейронов.
- Бэкенд, аккаунты, сохранение на сервере.
- Редактирование данных коннектома.
- 3D-визуализация.

## 7. Структура репозитория (ориентир)

```
/app          — компоненты $mol (*.view.tree, *.view.ts)
/data         — итоговый connectome.json
/scripts      — конвертер исходных CSV → JSON, README с источниками

README.md     — что это, скриншот, ссылка на демо, атрибуция данных
```

## 8. Критерии приёмки

1. Открываю демо-ссылку: за секунду вижу весь коннектом в послойной раскладке, читаемо, не «волосяной шар».
2. Ввожу в поиск «ASH» — фокус на ASHL/ASHR, вижу их связи и панель со списком.
3. Выбираю путь ASH → AVA: подсвечивается известный escape-каскад.
4. Отключаю gap junctions и ставлю min weight = 5 — граф прореживается мгновенно.
5. Копирую URL, открываю в приватной вкладке — вид полностью восстановился.
6. Отключаю сеть, перезагружаю страницу с локальной статики — всё работает.
7. Lighthouse performance ≥ 90 на десктопе.

## 9. Этапы

1. **Данные**: конвертер CSV → JSON, валидация против известных фактов (302 нейрона, число рёбер в пределах опубликованных значений).
2. **Скелет**: проект mam, статичный рендер графа в послойной раскладке.
3. **Интерактив**: hover, фокус, пан/зум.
4. **Фильтры + поиск + панель деталей.**
5. **Пути, URL-состояние, полировка, адаптив.**
6. **README, скриншоты, деплой на GitHub Pages.**

## Что сделано иначе, чем в ПРД

Осознанные отклонения, все — в сторону расширения:

- **Мышцы и прочие клетки-мишени в графе.** Помимо 302 нейронов датасет несёт 148 мышечных и других
  концевых клеток из того же edge list — иначе критерий приёмки №3 (`ASH → AVA → мышечные
  мотонейроны`) обрывается на мотонейронах. Они выключаются фильтром `Muscle` / `Other`.
- **Расширенный union типов.** К `sensory | inter | motor | poly` добавлены `muscle`, `other` и
  `unknown` — последний нужен для CANL и CANR, у которых WormAtlas не указывает функциональный класс.
- **Только Cook 2019.** White 1986 / Varshney как второй слой не включён: сравнение датасетов
  отнесено ПРД к V2. Конвертер и формат данных рассчитаны на несколько датасетов, но собран один.
- **Конвертер на Node без TypeScript.** `scripts/build-data.mjs` — обычный ESM-модуль с JSDoc-типами.
  Это не каприз: MAM компилирует любой `.ts` в дереве модуля, и серверный скрипт рядом с клиентским
  кодом рискует уехать в бандл.
- **Анатомические координаты сложены в данные, раскладки по ним нет.** Поля `ap` и `dv` (положение
  сомы по осям тела) есть в `connectome.json` и в бандле — это и есть «заложить архитектурно» для
  анатомической раскладки из V2.
- **Числа.** Итог конвертера: 4681 химический синапс и 1359 gap junction — 6040 связей вместо
  «~7000» из ПРД. В исходнике gap junctions перечислены с обеих сторон, и они схлопнуты в одно
  ненаправленное ребро.
